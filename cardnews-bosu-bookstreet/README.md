# 보수동 책방골목 카드뉴스

- 형식: Instagram 1:1 정사각형 (1080 × 1080 기준), 5장
- 편집: `index.html`의 카드별 텍스트, `styles.css`의 색·레이아웃 및 1번 카드 입장 효과, `motion.js`의 카드 선택 제어
- 미리보기: 브라우저에서 `index.html?card=1`을 엽니다.
- 출력: 1:1 카드 5장이 `previews/`에 있습니다. 1번 카드에는 텍스트 입장 효과만 적용되며 MP4 출력은 사용하지 않습니다.

## 카드 구성

1. 시간의 골목 — 보수동 책방골목 소개
2. 시작 — 1950년대 피난민 헌책 노점에서 형성된 역사
3. 발견 — 새책·헌책·고서
4. 산책법 — 골목을 즐기는 세 가지 방법
5. 저장/방문 CTA — 부산 중구 보수동1가
